# AI Text Summarizer

A simple web app that summarizes long text into concise summaries using a Hugging Face transformer model with FastAPI backend and a lightweight HTML/JS frontend.

## Features
- Paste text or upload `.txt` files
- AI-powered summarization using Hugging Face transformers
- Clean and simple frontend
- FastAPI backend API

## Tech Stack
- **Backend**: Python, FastAPI, Hugging Face `transformers`
- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Docker-ready
